# Roundtable 商业模式文档

## 1. 产品定位

**Roundtable（圆桌会议）** 是一款面向会议内容复盘与个人重大决策的 AI 专家圆桌系统。

不同于通用大模型的"单点问答"，Roundtable 模拟真实专家团队的工作方式：多角色并发分析、两轮交叉辩论、Supervisor 审查校验、人在回路确认——最终输出一份结构化、可追溯、多人共识驱动的决策报告。

**一句话定位**：让每一次会议和每一个重大决策，都经得起专家团队级别的审视。

## 2. 市场分析

### 2.1 目标市场

| 维度 | 描述 |
|------|------|
| **核心市场** | 中小型企业会议复盘、创业公司决策支持、个人职业/投资/生活重大决策 |
| **市场规模** | 中国企业级 SaaS 协同办公市场 2024 年约 800 亿元，AI 加持的决策辅助工具处于爆发前夜 |
| **增长驱动** | 远程办公常态化、会议效率低下（平均 31% 会议时间被浪费）、个人决策信息过载 |

### 2.2 竞争格局

| 竞品类型 | 代表产品 | Roundtable 差异化 |
|----------|----------|-------------------|
| 通用 AI 聊天 | ChatGPT、Claude、DeepSeek | 单轮对话 vs 多 Agent 辩论 + 审查校验 |
| 会议转写工具 | 讯飞听见、飞书妙记 | 仅转写 vs 转写 + 智能分析 + 决策报告 |
| 决策辅助软件 | Decision Lens | 重型 B2B 软件 vs 轻量 API + 前端，零门槛接入 |
| 专家咨询平台 | 麦肯锡、专家网络 | 数万元/次 vs 数元/次，7×24 可用 |

### 2.3 市场痛点

1. **会议开完就忘**：没有结构化复盘，行动项遗漏率高达 40%
2. **决策靠直觉**：缺乏多视角挑战， Confirmation Bias（确认偏误）严重
3. **专家咨询贵**：外部顾问费用高、响应慢、不可规模化
4. **AI 回答不可信**：通用模型"幻觉"多，缺乏证据绑定和审查机制

## 3. 客户画像

### 3.1 企业用户（B2B）

| 角色 | 痛点 | 使用场景 |
|------|------|----------|
| **产品经理** | 功能优先级争论不休 | 上传 PRD 讨论录音，让 AI 专家团给出共识结论 |
| **创业者/CEO** | 战略决策缺乏外部挑战 | 输入"要不要转型/融资/裁员"，获得魔鬼代言人视角 |
| **项目经理** | 会议纪要流于形式 | 上传会议录音，自动生成带行动项和负责人的报告 |
| **HR/OD** | 组织诊断缺乏数据 | 批量分析团队会议，发现重复议题和决策盲区 |

### 3.2 个人用户（B2C）

| 角色 | 痛点 | 使用场景 |
|------|------|----------|
| **职场进阶者** | 职业选择焦虑 | "该接受这份 offer 还是留在原公司？" |
| **投资者** | 投资判断情绪化 | "这只股票/这个房产该不该买？" |
| **自由职业者** | 项目取舍困难 | "接不接这个客户？定价多少？" |
| **学生/研究者** | 论文/课题方向迷茫 | "这个研究方向值不值得深入？" |

## 4. 三阶段变现路径

### Phase 1：个人用户验证期（0-6 个月）

- **目标**：验证产品价值，积累种子用户，打磨核心体验
- **策略**：免费增值（Freemium）
- **收费点**：
  - 免费：每月 3 次个人圆桌分析
  - 付费：不限次数 + 导出 PDF 报告 + 历史记录搜索
- **获客**：小红书/即刻/推特内容营销、KOL 推荐、Product Hunt 首发

### Phase 2：团队渗透期（6-18 个月）

- **目标**：从个人用户向工作场景渗透，进入企业采购流程
- **策略**：团队版订阅 + API 开放平台
- **收费点**：
  - 团队版：按席位收费，支持会议录音批量上传、团队协作看板
  - API：按调用量计费，嵌入飞书/钉钉/企业微信
- **获客**：企业协作软件市场、行业垂直场景（法律、医疗、教育）

### Phase 3：平台生态期（18-36 个月）

- **目标**：成为决策基础设施，构建专家 Agent 生态
- **策略**：Marketplace + 企业私有化部署
- **收费点**：
  - 专家 Agent 市场：第三方开发者上架专属领域 Agent，平台抽成 20%
  - 私有化部署：大型企业的本地版，年费 10-50 万元
  - 数据洞察服务：基于匿名化数据的行业决策趋势报告

## 6. 财务预测（保守估算）

### 6.1 假设条件

- 月活跃用户（MAU）增长：首年 1 万 → 第三年 50 万
- 付费转化率：免费→专业版 3%，专业版→专家版 10%
- 团队版客户：首年 50 家 → 第三年 2,000 家
- 平均客单价（ARPPU）：个人 ¥120/月，团队 ¥800/月

### 6.2 三年收入预测

| 年度 | 个人付费用户 | 团队客户 | 年收入（万元） |
|------|-------------|---------|---------------|
| **第 1 年** | 300 人 | 50 家 | ≈ 80 |
| **第 2 年** | 5,000 人 | 500 家 | ≈ 1,200 |
| **第 3 年** | 25,000 人 | 2,000 家 | ≈ 5,500 |

### 6.3 成本结构

| 成本项 | 占比 | 说明 |
|--------|------|------|
| **LLM API** | 35-45% | 主要成本，随多 Agent 并发和调用量增长 |
| **服务器/带宽** | 10-15% | 云服务器、对象存储、CDN |
| **研发** | 25-30% | 后端、前端、模型优化 |
| **市场/销售** | 15-20% | 内容营销、渠道合作、销售团队 |
| **管理/其他** | 5-10% | 行政、法务、财务 |

**盈利路径**：第 2 年下半年实现单月盈亏平衡，第 3 年实现全年盈利。

## 7. 关键风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| **LLM 成本波动** | 高 | 多 Provider 路由（已支持）、本地小模型降级、Token 预算硬限制 |
| **模型幻觉** | 高 | 证据绑定、Supervisor 审查、人在回路确认（产品核心差异化） |
| **用户留存低** | 中 | 记忆系统（自动记录决策模式）、复盘提醒、决策追踪闭环 |
| **竞品复制** | 中 | 先发优势 + 用户决策数据飞轮 + 专家 Agent 生态壁垒 |
| **数据合规** | 中 | 企业版支持私有化部署、数据加密、审计日志 |
